## Overview
This lab applies Excel's data analysis capabilities to a supplied sales dataset. It demonstrates PivotTable-based reporting, formula-driven calculations, lookup functions, and conditional formatting.

## Tasks completed

### Task 01 — PivotTable analysis
- Organized country and state data in hierarchical PivotTables.
- Summarized revenue, cost, and profit by country; created a calculated profit field.
- Displayed revenue as currency and percentage of total.
- Filtered cost analysis by customer gender.
- Produced year/month revenue summaries by country.

### Task 02 — Excel formulas
Practised numeric, conditional, text and date functions, including:
`MAX`, `MIN`, `IF`, `IFS`, `LEN`, `LEFT`, `RIGHT`, `TEXT`, `TRIM`, `SUBSTITUTE`, `SUM`, `SUMIF`, `SUMIFS`, `COUNT`, `COUNTIF`, `DAYS`, and `NETWORKDAYS`.

### Task 03 — Data lookups
Used `XLOOKUP` for lookups, exact matches, multi-column results and reverse search ordering; combined lookup and summary functions, and practised `VLOOKUP`.

### Task 04 — Conditional formatting
Applied value thresholds, data bars, colour scales, and date-based formatting to highlight patterns in spreadsheet data.

## Skills demonstrated
**Excel · PivotTables · Data Aggregation · Formula-Based Analysis · XLOOKUP/VLOOKUP · Conditional Formatting · Data Reporting**
