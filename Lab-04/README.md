# Lab 04 — Power BI Data Integration, Modelling & Dashboards

**Course:** SRT411 — Digital Data Analytics  
**Tools:** Power BI Service, Power BI Desktop, Power Query, MySQL, Excel/CSV  
**Evidence:** 15-page academic lab report (PDF to be uploaded separately)

## Overview

This lab demonstrates connecting spreadsheet and MySQL sales data to **Microsoft Power BI**, building relationships between imported tables, creating interactive data visualizations, and publishing and sharing reports.

## Tasks completed

### 1. Power BI and Power Query setup
- Accessed **Power BI Service** and configured **Power BI Desktop**.
- Connected a sales CSV/Excel dataset through Power Query.
- Previewed and ingested data for analysis in the web and desktop interfaces.

### 2. Excel/CSV data visualization
- Built a **profit-by-country** stacked column chart and **profit-by-month** line chart in Power BI Service.
- Created an interactive **Country slicer** to filter the report.
- Used Power BI Desktop to visualize **profit by age group** and **profit by country/product category**.
- Formatted chart titles, colours, labels and backgrounds for readable reporting.

### 3. MySQL integration and data modelling
- Connected Power BI Desktop to MySQL and imported **Sales**, **Products**, and **Customers** tables.
- Explored the relationships **Sales → Products (Product)** and **Sales → Customers (Country)**.
- Used the model to analyze profit by country and product subcategory, revenue by subcategory, and order quantity by product.

### 4. Interactive reporting, publication and sharing
- Combined multiple charts into a dashboard and used a **Country slicer** for interactive filtering.
- Published the report to **My Workspace** in Power BI Service.
- Documented the dashboard-sharing workflow.
